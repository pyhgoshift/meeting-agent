# ActionItem_run 시트 연동 설정

주간보고에서 도출한 액션아이템을 구글 시트에 넣기 위한 준비입니다. **한 번만** 하면 됩니다.

대상 시트: `ActionItem_run` — 탭 이름 `시트1`

---

## 1. 스크립트 **추가** 하기

> ⚠️ **이미 있는 `today.gs` 를 덮어쓰지 마세요.** 그 파일이 행 정렬과 색칠을 담당합니다.
> 지우면 오늘 날짜 강조가 사라집니다. **파일을 새로 만들어서** 붙여넣으세요.

1. 시트를 열고 **확장 프로그램 → Apps Script**
2. 왼쪽 **파일** 목록에서 **＋ → 스크립트** 를 눌러 파일을 하나 추가하고 이름을 `actionitem` 으로
3. 새로 만든 빈 파일에 [`actionitem-sheet.gs`](./actionitem-sheet.gs) 내용을 붙여넣기

한 프로젝트 안에 파일이 여러 개 있어도 됩니다. `today.gs` 는 그대로 두세요.

> `doGet` / `doPost` 는 프로젝트 전체에 **하나씩만** 있을 수 있습니다.
> `today.gs` 에는 없으니 충돌하지 않습니다.

## 2. 비밀번호 정하기

붙여넣은 코드 위쪽의 이 줄을 찾습니다:

```javascript
const TOKEN = '여기를_길고_무작위한_문자열로_바꾸세요';
```

따옴표 안을 **길고 아무 의미 없는 문자열**로 바꾸세요. 키보드를 무작위로 두드린 30자 이상이면 됩니다. 이 값을 **메모해 두세요** — 4번에서 씁니다.

이게 없으면 웹훅 주소를 알아낸 사람이 시트에 아무 행이나 쓸 수 있습니다.

**저장**(💾 아이콘)을 누릅니다.

## 3. 배포하기

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(⚙️) → **웹 앱** 선택
3. 설정:
   - **실행 사용자**: 나
   - **액세스 권한**: **모든 사용자**
4. **배포** → 권한 승인(본인 구글 계정 선택 → 고급 → 이동 → 허용)
5. 나온 **웹 앱 URL** 을 복사합니다 (`https://script.google.com/macros/s/AKfy.../exec`)

> **액세스 권한을 "모든 사용자"로 두는 이유**: NAS 의 봇이 구글 로그인 없이 호출해야 하기 때문입니다. 대신 2번에서 정한 토큰이 쓰기를 막습니다.

## 4. NAS 에 값 넣기

`/volume1/docker/meeting-agent/.env` 에 두 줄을 추가합니다.

**⚠️ 파일 맨 끝에 빈 줄이 있는지 먼저 확인하세요.** 줄바꿈 없이 이어붙으면 앞 줄 값이 망가집니다(전에 터널 토큰이 이렇게 깨진 적이 있습니다).

```
ACTIONITEM_SHEET_URL=3번에서_복사한_웹앱_URL
ACTIONITEM_SHEET_TOKEN=2번에서_정한_문자열
```

그리고 스케줄러로 배포를 한 번 실행합니다.

## 잘 됐는지 확인

브라우저에서 웹 앱 URL 을 그냥 열어보세요. 이런 게 나오면 성공입니다:

```json
{"ok":true,"headers":["상태","시작일","종료일",...],"rows":[...],
 "categories":["배포","시스템점검"],"teams":["AI개발팀","인프라팀"]}
```

`rows` 에 기존 행이, `categories`·`teams` 에 지금 시트에서 쓰이는 분류 값이 들어있으면 정상입니다.

## 안 될 때

| 증상 | 원인 |
|---|---|
| `헤더 행을 찾지 못했습니다` | `작업내용` 열이 없거나 헤더가 10번째 줄보다 아래 |
| `시트를 찾을 수 없습니다` | 탭 이름이 `시트1` 이 아님 → 코드의 `SHEET_NAME` 수정 |
| 오늘 날짜 강조가 이상함 | 이 스크립트와 무관. `today.gs` 문제 — 아래 참고 |
| 페이지가 로그인을 요구함 | 배포 시 액세스 권한이 "모든 사용자"가 아님 |
| `토큰이 일치하지 않습니다` | `.env` 값과 스크립트의 `TOKEN` 이 다름 |

## 코드를 고친 뒤에는

Apps Script 를 수정하면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다.
저장만 해서는 웹 앱에 적용되지 않습니다. URL 은 그대로 유지됩니다.

## 참고: today.gs 와 현재 시트가 어긋나 있습니다

시트에서 열을 지우신 뒤 `today.gs` 의 고정된 숫자들이 실제 구조와 맞지 않습니다.

| `today.gs` | 실제 시트 |
|---|---|
| `startRow = 5` (5행부터 처리) | 데이터는 **3행부터** |
| `setFrozenRows(4)` | 헤더는 **2행** |
| `styleColStart = 9, styleColCount = 11` (I~S열 색칠) | 데이터는 **L열까지** |

그래서 **3~4행은 처리에서 빠지고**, 색칠은 데이터 오른쪽 빈 칸까지 번집니다.

고치려면 `today.gs` 의 세 값을 바꾸면 됩니다:

```javascript
var startRow = 3;          // 5 → 3
var styleColStart = 1;     // 9 → 1   (A열부터)
var styleColCount = 12;    // 11 → 12 (L열까지)
```

`setFrozenRows(4)` 도 `2` 로 바꾸는 게 맞습니다.

다만 이 숫자들은 **열을 또 지우면 다시 어긋납니다.** 근본적으로는 헤더 이름으로 위치를
찾는 방식(이 파일의 `readSheet_` 처럼)이 안전합니다.
