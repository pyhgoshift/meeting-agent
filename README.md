# 🎙️ AI-Meeting Agent (회의록 자동 요약 및 분배 봇)

## 📌 이건 뭔가요? (초간단 요약)
핸드폰으로 회의를 녹음하고, 그 녹음 파일을 제 개인 서버(NAS)에 올리기만 하면 끝!
AI가 알아서 대화를 듣고 텍스트로 바꾸며, 똑똑하게 요약하고 할 일을 정리한 뒤 **Slack(슬랙), Notion(노션), Google Sheets(구글 시트)**로 착착 배달해 주는 **"나만의 완벽한 인공지능 비서"**입니다. 

중학생도 이해할 수 있을 만큼 쉽고, 모든 과정이 100% 자동화되어 있어서 사용자는 그저 **"녹음하고 올리기만"** 하면 됩니다.

---

## 🚀 기막히게 쉬운 작동 원리 (핸드폰 녹음부터 슬랙 도착까지)

1. **📱 회의 녹음하기**: 스마트폰 녹음기 앱으로 회의나 미팅 내용을 녹음합니다. (예: `기획회의.m4a`)
2. **☁️ NAS에 툭 던지기**: 시놀로지 DS file 앱 등을 켜서, NAS 안에 미리 만들어둔 `recording` 폴더에 방금 녹음한 파일을 업로드합니다.
3. **🤖 AI가 꿀꺽 (Whisper)**: 폴더를 몰래 감시하던 봇이 파일을 발견하자마자 낚아채서 텍스트(대본)로 변환합니다. (※ 현재 1회 최대 25MB 제한이 있습니다)
4. **🧠 딥시크(DeepSeek)의 브레인 스토밍**: 변환된 대본을 읽고 **[전체 요약, 결정된 사항, 누가 뭘 해야 하는지(할일), 다음 일정]**을 핵심만 쏙쏙 뽑아냅니다.
5. **🚚 3단 콤보 자동 배달**:
   - 💬 **Slack (슬랙)**: 1~3분 만에 내 폰과 PC의 슬랙으로 **"삐빅! 요약 완료!"** 푸시 알림과 함께 주요 내용이 날아옵니다. (글자수가 너무 길면 절대 씹히지 않고 강제 텍스트 모드로 변환되어 무조건 알람을 울립니다!)
   - 📝 **Notion (노션)**: 깔끔하게 정리된 회의록과 대화 원본 전체가 예쁜 노션 페이지로 영구 저장됩니다.
   - 📊 **Google Sheets (구글 시트)**: 엑셀 파일(시트)에 오늘 날짜와 회의 제목, 요약이 한 줄씩 차곡차곡 데이터베이스로 쌓입니다.
6. **🧹 자동 청소**: 처리가 끝난 뚱뚱한 녹음 파일은 `.archive` 라는 창고 폴더로 휙 던져버려서 NAS와 폰의 용량을 아껴줍니다.

## 🎛️ 무적의 '컨트롤 센터' (웹 대시보드)

로봇이 멈췄는지 잘 돌아가는지 까만 해커 화면(터미널)을 볼 필요가 전혀 없습니다!
`https://meeting.pyhgoshift.com`으로 접속하면 아주 세련된 **다크 모드 + 투명 유리 효과(Glassmorphism)**가 적용된 컨트롤 센터가 열립니다.

- 📊 **상태 모니터링**: 내가 올린 파일이 지금 'AI가 듣고 있는 중'인지, 아니면 '용량 초과로 에러가 났는지' 15초마다 새로고침되며 실시간으로 보여줍니다. 과거에 처리한 모든 파일의 성공/실패 이력도 싹 다 남습니다.
- 🧠 **AI 뇌 조종석**: AI의 성격이나 요약 방식을 바꾸고 싶다면? 여기서 한글 프롬프트를 메모장 고치듯 쓱싹 수정하고 [저장]만 누르면 AI가 즉시 똑똑해집니다.
- 🎨 **슬랙 템플릿**: 슬랙에 날아오는 메시지 디자인이나 이모티콘을 내 맘대로 꾸밀 수 있습니다.
- ⚙️ **환경 변수**: 각종 복잡한 API 키를 안전하게 보관하고 관리합니다.

## 🌐 외부 접속의 마법사, Cloudflare Tunnel + Access

회사나 밖의 카페, 심지어 폰에서도 앱 설치 없이 브라우저만으로 대시보드에 접속할 수 있습니다. 포트포워딩도, VPN 앱도 필요 없습니다!

- **주소**: 아무 브라우저에서 `https://meeting.pyhgoshift.com` 접속
- **인증**: Cloudflare Access가 먼저 이메일 인증 화면을 띄웁니다. `pyhgoshift@gmail.com`을 입력하면 메일로 일회용 코드(OTP)가 날아오고, 코드를 입력하면 24시간 동안 자유롭게 사용 가능합니다. 등록된 이메일이 아니면 아예 문전박대당합니다.
- **원리**: NAS의 `cloudflared` 컨테이너가 Cloudflare로 아웃바운드 터널만 뚫습니다(`meeting-agent` 터널). NAS에는 어떤 포트도 열려있지 않아서, Cloudflare의 인증을 통과한 요청만 대시보드에 도달할 수 있습니다.
- **설정 위치**: Cloudflare Zero Trust 대시보드 → 네트워크 → 커넥터(`meeting-agent` 터널) / 액세스 제어 → 애플리케이션(`meeting` 앱)
- **필수 환경변수**: `.env`에 `CLOUDFLARE_TUNNEL_TOKEN=<터널 토큰>`이 있어야 합니다. 토큰은 Zero Trust → 커넥터 → meeting-agent 터널 페이지에서 복사할 수 있습니다.

## 🛠️ 처음 온 사람을 위한 초간단 설치 가이드 (따라 하기)

1. **NAS 준비**: 시놀로지 NAS 패키지 센터에서 `Container Manager (Docker)`를 설치합니다.
2. **폴더 만들기**: NAS의 File Station을 열고 `homes/본인계정/recording` 이라는 폴더를 만듭니다.
3. **배포 스크립트 세팅**: 시놀로지 **[제어판] ➡️ [작업 스케줄러]**에서 새로운 사용자 정의 스크립트(root 권한)를 하나 만들고 아래 코드를 넣습니다.
   ```bash
   bash /volume1/docker/meeting-agent/deploy.sh
   ```
4. **원클릭 실행**: 작업 스케줄러에서 방금 만든 작업을 [실행] 누르고 3분만 기다리면 AI 로봇이 눈을 뜹니다.
5. **마법의 시작**: 이제 폰으로 회의를 녹음하고 `recording` 폴더에 툭 던져두기만 하면 끝입니다! 커피 한 잔 내리는 동안 슬랙으로 요약본이 배달될 것입니다. ☕
